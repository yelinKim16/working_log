# 근무일지

체크리스트 형태의 근무일지 웹사이트입니다. 데이터는 **구글 드라이브의 `근무일지_데이터.json` 파일 하나**에 저장되고, 어느 PC에서든 같은 구글 계정으로 로그인하면 같은 데이터를 볼 수 있어요. 브라우저에도 사본이 남아서 인터넷이 잠깐 끊겨도 작업할 수 있습니다.

## 실행

프로젝트 폴더에서:

```
npx http-server -p 5173 -c-1
```

그다음 브라우저로 http://localhost:5173 에 접속하세요.
(파일을 더블클릭해서 열면 구글 로그인이 동작하지 않아요. 반드시 위 주소로 여세요.)

## 구글 드라이브 연결 (처음 한 번만)

### 1. Google Cloud 프로젝트 만들기
1. https://console.cloud.google.com 접속 → 데이터를 저장할 **본인 구글 계정**으로 로그인
2. 상단의 프로젝트 선택 → **새 프로젝트** → 이름 `근무일지` → 만들기

### 2. Google Drive API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Drive API` 검색 → **사용** 클릭

### 3. OAuth 동의 화면 (Google 인증 플랫폼)
1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** (또는 "Google 인증 플랫폼") → **시작하기**
2. 앱 이름 `근무일지`, 지원 이메일은 본인 이메일
3. 대상(Audience): **외부** 선택. 회사 Workspace 계정이면 **내부**를 선택해도 됩니다.
4. 연락처 이메일 입력 → 동의 → 만들기
5. **대상(Audience)** 메뉴 → **테스트 사용자 → 사용자 추가** → 본인 Gmail 주소 추가
   (앱을 "게시"하지 않아도 되고, 테스트 사용자로 등록된 계정만 로그인할 수 있어요.)

### 4. OAuth 클라이언트 ID 발급
1. **클라이언트(Clients)** 메뉴 → **클라이언트 만들기**
2. 애플리케이션 유형: **웹 애플리케이션**
3. **승인된 자바스크립트 원본**에 추가:
   - `http://localhost:5173`
   - 나중에 인터넷에 올린다면 그 주소도 추가 (예: `https://아이디.github.io`)
4. 승인된 리디렉션 URI는 비워둬도 됩니다 → 만들기
5. 표시되는 **클라이언트 ID**(`....apps.googleusercontent.com`)를 복사
   (클라이언트 "보안 비밀번호"는 필요 없어요)

### 5. 사이트에 붙여넣기
`config.js`를 열어서 붙여넣으세요.

```js
window.WORKLOG_CONFIG = {
  GOOGLE_CLIENT_ID: '복사한_클라이언트_ID.apps.googleusercontent.com',
};
```

새로고침하면 로그인 화면이 나와요. **Google 계정으로 로그인** → 계정 선택 → **드라이브 권한 체크** → 완료.
로그아웃은 왼쪽 아래 이름 옆 **⋯ → 로그아웃**에서 할 수 있어요. 로그아웃하면 이 PC에 남은 사본도 지워져요.
"확인되지 않은 앱" 경고가 나오면 **고급 → 근무일지(으)로 이동**을 누르세요. 본인이 만든 앱이라 괜찮습니다.

## 다른 PC에서 쓰기

1. 이 폴더 전체를 다른 PC로 복사해서 똑같이 실행하세요. 또는 인터넷에 올려서 주소로 접속해도 됩니다.
2. **드라이브 연결** → 같은 구글 계정으로 로그인하면 드라이브의 데이터를 불러옵니다.
   (처음 연결할 때 "드라이브 내용 사용 / 이 PC 내용 사용" 중 하나를 고르게 돼요. 다른 PC에서 쓰던 데이터를 가져오려면 **드라이브 내용 사용**)

## 알아둘 점

- **권한 범위:** 사이트는 `drive.file` 권한만 사용해서, **자기가 만든 파일 하나에만** 접근합니다. 드라이브의 다른 파일은 볼 수 없어요.
- **자동 저장:** 수정하면 1~2초 뒤 드라이브에 자동으로 저장돼요. 왼쪽 아래에 저장 상태가 표시됩니다.
- **로그인 유지:** 보안상 로그인은 약 1시간 동안 유지돼요. 만료되면 **다시 로그인** 버튼을 한 번 눌러주세요. 그사이 수정한 내용은 이 PC에 남아 있다가 다시 로그인하면 올라갑니다.
- **동시 수정:** 두 PC에서 동시에 수정하면 "어느 쪽 데이터를 쓸지" 물어봐요.
- **백업:** 드라이브의 파일 버전 기록이 남고, ⋯ 메뉴의 **백업 내보내기**로 따로 저장할 수도 있어요.
